# Каталог

Минимальный каталог товаров: Next.js, FastAPI, бот aiogram 3, PostgreSQL, MinIO.

Состояние сервисов не хранится в памяти процесса и не пишется на локальный диск. Товары лежат в PostgreSQL, фото — в MinIO. Повтор одного и того же события Telegram не создаёт второй товар.

## Запуск

1. В `.env` заполните `BOT_TOKEN` и `ADMIN_IDS` (числовой id администратора).
2. Поднимите стек:

```bash
docker compose up --build
```

3. Каталог: http://localhost:3000
4. API: http://localhost:8000/products

В боте команда `/start` отвечает «У меня есть товар» и показывает кнопку Mini App. Администратор нажимает «Создать товар» и следующим сообщением отправляет фото с подписью-названием.

## Несколько инстансов

API и сайт можно поднять так:

```bash
docker compose up --build --scale api=2 --scale web=2
```

Без `WEBHOOK_URL` события Telegram читает только один процесс: второй ждёт и отвечает на `/health`. Так два опроса не забирают одну очередь.

Для двух рабочих реплик бота задайте в `.env` публичный адрес и общий секрет:

```
WEBHOOK_URL=https://ваш-домен/webhook
WEBHOOK_SECRET=длинная-случайная-строка
```

Прокси должен отправлять `POST /webhook` на порт `8080` бота. `WEBAPP_URL` и `PUBLIC_API_URL` на сервере должны быть адресами, которые открывает телефон. Для кнопки Mini App нужен HTTPS.
